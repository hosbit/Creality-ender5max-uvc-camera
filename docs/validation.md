# 验证记录与证据边界

记录日期：2026-10-17（北京时间）。来自一台已授权设备的实测与用户 App 确认，未包含账号信息、现场图片或原始云日志。

| 阶段 | 结果 | 边界 |
|---|---|---|
| USB | 下方 USB 口识别 UVC，主节点 video4 | 一台机器，不推断其他端口设计 |
| LAN / Orca | 640×480 JPEG 正常，参数和视频共存 | Device UI 留空 |
| HTTP 计数 | 两轮各 120 帧，约 10.014 / 10.012fps | HTTP 到达速率，非光学曝光帧率 |
| 云 2fps | 180 秒输出 360 帧，App 正常 | 空闲短测，单核约 22%～24% |
| 云 5fps | 20 秒预检、180 秒 App 确认正常 | 单核约 55%，未覆盖长时间打印 |
| 5fps 帧发布抽样 | 60 次观察，首末间隔 11.8573 秒，约 4.9758fps | memfd 发布计数，不是手机渲染帧率 |
| 常驻进程 | 重复启动不产生多份；TERM 子进程后自动恢复 | 没有模拟所有系统级故障 |
| 停止 | 清理自身 socket、ready、PID；LAN 原进程和快照正常 | 不修改原厂配置 |
| 实际正常重启 | LAN 与云均自启，App 刷新后用户确认视频正常 | 一次完整重启验收 |
| 常驻越过旧时限 | 同一云 PID 连续运行 185.24 秒；900 帧约 181.13 秒 | 证明不再受 180 秒窗口限制，不代表长稳测试 |

## 运行代码与新增工具分开说明

`src/` 中四个运行文件与上述设备已验证文件逐字节一致，其指纹记录在 `package.json`。公开整理期间没有修改设备上运行的服务，也没有再次进行高负载采集。

新增 `tools/manage.py` 安装器通过 12 项临时根目录测试，覆盖两组件安装、重复安装、保留已有 LAN、仅卸载云、全部移除顺序、文件或链接冲突、失败回退、修改文件拒绝执行、依赖保护、路径注入拒绝与损坏包拒绝。

测试使用伪服务控制器，不启动真实服务，不打开视频设备，不修改真实 `/usr/data` 或 `/etc/init.d`。Windows 隔离测试已通过；安装器尚未在另一台全新打印机上端到端验收。Linux 发布环境应继续执行同一测试集。

语法检查、发布内容检查和源码校验的执行方式见 [CONTRIBUTING.md](../CONTRIBUTING.md)。失败的高规格试验见[兼容性说明](compatibility.md)。
