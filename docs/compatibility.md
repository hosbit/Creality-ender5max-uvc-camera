## 当前限制

1. 摄像头匹配名固定为 `HDI Webcam USB`。其他型号名称不同会等待，不能声称所有 UVC 均可用。
2. `input_uvc.so` 的 `-r` 参数会触发符号缺失，当前依赖默认 640×480。若驱动默认格式不同，云守护会继续等待合适源。
3. LAN 请求 / 驱动报告 5fps，但 HTTP 实测约 10fps，原因尚未确定。
4. 5fps 桥接空闲短测约占单核 55%；长时间打印中的资源影响未验证。
5. 没有经过固件更新、连续数日运行、拔插循环或其他设备的完整回归验证。
6. 原厂 App、网络与已绑定账号仍是云路径的前提；本项目不替代云服务。

## 不包含的高规格试验

原厂启动脚本请求 1920×1080、15fps，不是本项目目前可用规格。一次尝试该参数的采集试验后，设备的 SSH、视频与云连接失去响应，自动恢复未完成，需要现场重启。

没有保留故障时的完整设备日志，根因尚未确认。不能断言是内存、编码器、USB 或帧率中的某一项，也不能把失败归因于单独的 15fps。这个试验同时改变了分辨率、帧率及采集方式。

本仓库不提供该试验脚本，也不建议直接重做。当前运行代码保持已验证的 640×480、5fps 路径。
